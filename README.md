# EnonPlatform

El proyecto esta creado en unity, en la version 2022.3.22 - *3D Built-in* 
El juego trata de un plataformas 3d donde el robot tiene que pasar por diferentes obstaculos como plataformas flotantes, plataformas que se mueven, plataformas que caen y escaleras, saltos, tambien cuenta con monedas que son recolectables y vidas al rededor del mapa, el objetivo principal es llegar a la meta y no perder las vidas antes de estar en la meta.
